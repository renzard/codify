Codify is an open-source, offline-first interactive learning app designed to teach programming concepts step by step.

Features:
- Interactive Python code editor with real-time on-device code execution via Chaquopy.
- Support for multiple programming topics including Python, HTML/CSS, and Linux commands.
- Interactive quizzes and fill-in-the-blank exercises after each lesson.
- Dual language interface (English & Greek).
- Dark-themed code editor with monospace typography.
- 100% free and open-source (GPL-3.0), no ads, no tracking, no permissions needed.
